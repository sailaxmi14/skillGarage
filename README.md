# 🎓 Skill Garage – Online Course Purchasing Platform

## 📌 About the Project

**Skill Garage** is an online course purchasing platform developed to provide a seamless learning experience for users and efficient course management for administrators.

The application consists of two main modules: **User Module** and **Admin Module**. Users can explore available courses, view course details, save their favourite courses, purchase courses, and access their enrolled courses. Administrators can manage courses, track purchases, and monitor user enrollments through a dedicated dashboard.

## ✨ Features

### 👤 User Module

- **Browse Courses:** Explore all available courses.
- **Course Details:** View detailed information about individual courses.
- **Save Courses:** Add favourite courses to the saved list.
- **Buy Courses:** Purchase courses using the Buy Now option.
- **My Courses:** View all purchased and enrolled courses.
- **User Dashboard:** Manage course-related activities in one place.

### 🛠️ Admin Module

- **Admin Dashboard:** Manage and monitor course-related activities.
- **Add Courses:** Add new courses with relevant details.
- **Update Courses:** Modify existing course information.
- **Delete Courses:** Remove unwanted courses.
- **View All Courses:** Display and manage all available courses.

## ⚙️ Installation and Setup

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/sailaxmi14/skillGarage.git
```

### 2. Navigate to the Project Directory

```bash
cd Skill-Garage
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open in Browser

Open the local URL displayed in your terminal, usually:

```text
http://localhost:5173/
```
